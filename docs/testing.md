# Стратегия проверок

Сейчас собственная реализация приложения отсутствует; upstream BCU подключён отдельно.
Этот документ задаёт будущие проверки и текущую проверку
документации. Названия библиотек тестирования выбираются при создании соответствующих модулей.

## Уровни

| Уровень | Что проверяем | Где |
| --- | --- | --- |
| Статические проверки | rustfmt, clippy, TypeScript, lint, сборка, зависимости | Windows CI с M0 |
| Unit | Нормализация, dedup, план, state machine, confidence и запреты | Синтетические фикстуры |
| Integration | Реестр в тестовой ветке, IPC, хранение и backup во временной области | Изолированная Windows-среда |
| UI | Поиск, фильтры, выбор, состояния, фокус, RU/EN | Mock backend и desktop smoke |
| VM end-to-end | Реальные установщики, UAC, reboot, сбои, восстановление | VM со снимками |
| Ручная доступность | Narrator, клавиатура, zoom, high contrast | Целевая Windows VM |

Mock UI в браузере не доказывает работу Tauri, UAC и Windows API. Такие проверки
дополняются настоящим desktop smoke. CI не запускает системное удаление на постоянном runner.

## Связь с требованиями

| Сценарий | Требования | Ожидаемый результат |
| --- | --- | --- |
| HKCU/HKLM, 32/64 views, access denied, Unicode, битые значения | INV-01, INV-02, INV-07 | Полный доступный список без падения; ошибки и unknown видны |
| Одно имя, разные product codes и scopes | INV-03 | Разные продукты не склеены |
| Unknown size, shared folder, отмена подсчёта | INV-04, LIST-01 | Нет ложного нуля и двойного учёта; UI отзывчив |
| Экспорт CSV с `=`, `+`, `-`, `@` и спецсимволами | LIST-04 | Нет исполнения формул; корректны escaping и Unicode |
| Пробелы/кавычки/Unicode в uninstall command | UN-01, UN-02 | Правильный executable и аргументы; неоднозначность блокируется |
| Изменение executable/плана после preview | UN-01, UN-02, CLN-08 | Устаревший план не исполняется; нужен новый просмотр |
| MSI 0, 3010, 1641, 1602, 1618 и неизвестный код | UN-03, UN-11 | Успех, reboot, отмена и конфликт различаются |
| NSIS/Inno без тихого режима | UN-04, UN-12 | Нет угаданных флагов и обещания отсутствия UI |
| Launcher завершился, дочерний процесс остался | UN-06 | Задание не завершено преждевременно |
| PID переиспользован / появился одноимённый чужой процесс | UN-06, UN-14 | Чужой процесс не связан и не завершается |
| Пауза и отмена оставшихся | UN-05, UN-07 | Текущее удаление не убито; следующие задания не стартуют |
| UAC denied / другой admin SID / helper отсутствует | UN-08 | Явная ошибка; правильный per-user scope; нет скрытого повторения |
| Exit 0, target всё ещё обнаружен | UN-09 | Нет безусловного успеха |
| Crash UI/helper/storage при выполнении | UN-10, HIST-01 | История согласована; команды не повторяются автоматически |
| Общий каталог издателя и похожие названия программ | CLN-03, CLN-04 | Общие/спорные объекты не выбраны автоматически |
| Документы, сохранения и профили | CLN-05 | Данные сохраняются по умолчанию |
| Junction/reparse point/hard link/UNC/подмена path | CLN-01, CLN-08 | Обход области и удаление защищённых объектов отклонены |
| Full disk / backup denied / повреждённый manifest | CLN-07, CLN-09 | Удаление заблокировано; исходные данные сохранены |
| Restore в занятое место / изменённый файл | CLN-07, CLN-09 | Нет молчаливой перезаписи; предлагается безопасная альтернатива |
| Чужой caller / remote pipe / replay / oversized message | UN-08, архитектура IPC | Helper отклоняет запрос без системных действий |
| Злонамеренный импорт с командами и абсолютными путями | LIST-06, TOOL-04 | Только preview сопоставления; команды из файла не исполняются |
| RU/EN, клавиатура, Narrator, 100/150/200% | UX-01–UX-03 | Основные действия доступны, фокус и статусы читаются |
| Личные имена/SID/пути в ошибках и логах | HIST-02, PRIV-01 | Экспорт редактирует личные поля, сетевой отправки нет |

## VM-матрица

M1: Windows 11 x64, обычный пользователь и администратор, RU/EN, оба registry views.
M2: добавить MSI, Inno Setup, NSIS, неизвестный EXE, per-user/per-machine, broken
uninstall entry, pending reboot и взаимодействие с Windows Installer.
M3: добавить обычные/общие каталоги, Unicode, ACL, занятые файлы, reparse points,
нехватку места, прерывание backup и конфликты restore.
M4: отдельный набор для каждого provider с несколькими библиотеками/scopes и offline режимом.
M6: чистая VM, обновление с предыдущей версии, portable/read-only каталог и установка WebView2.

В fixtures использовать собственные безопасные тестовые установщики там, где это
возможно; сторонние примеры брать только из проверенных источников с учётом лицензий.
Перед серией разрушительных сценариев создавать снимок и откатывать VM после серии.
Зафиксировать build Windows и версии установщиков. Не хранить установщики без права распространения.

## Отчёт проверки

```text
Дата / commit:
Требования и сценарии:
Среда: Windows build, scope пользователя, версии adapters/installer
Выполненные команды / шаги:
Ожидание:
Фактический результат:
Артефакты без личных данных:
Пропущенные проверки и причины:
Известные ограничения:
```

При баге сначала сохранить безопасный воспроизводимый пример, затем исправить и
добавить регрессионную проверку, если она защищает реальное поведение. Для форматирования
и мелких визуальных правок отдельные тесты, зеркалящие реализацию, не нужны.

## Условия выпуска

Все обязательные требования выпуска приняты; статические проверки и релевантные
unit/integration/VM-сценарии пройдены. Открытых release blockers из safety.md нет.
Известные ограничения отражены в интерфейсе и release notes. План rollback самого
приложения проверен отдельно от невозможности отката сторонних деинсталляторов.

## Проверка текущей документации

Проверить существование локальных ссылок, уникальность requirement IDs, покрытие
этапами, согласованность статусов, отсутствие заявлений о работающем приложении и
`git diff --check`. Собственные исходники приложения не созданы, поэтому build/tests не запускаются.
Текущая проверка документов: `python scripts/check_docs.py` из корня репозитория.
