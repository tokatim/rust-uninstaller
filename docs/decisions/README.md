## Следующие обязательные решения

| Вопрос | Когда решить | Что должно быть определено |
| --- | --- | --- |
| Имя продукта | До публичной поставки | Имя, package IDs, namespaces, ресурсы |
| Лицензия | До заимствования или распространения | Лицензия своего кода, совместимость зависимостей, уведомления |
| Точные toolchain/dependencies | M0 | Версии, lock-файлы, Windows SDK, package manager, CI |
| UI-проверка Tauri | Конец M0 | Таблица, клавиатура, Narrator, размер/запуск и WebView2 |
| Транспорт и авторизация IPC | До helper в M2 | ACL, handshake, caller identity, replay, admin с другим SID, race |
| Хранение и миграции | До истории в M2 | SQLite или альтернатива, schema, atomicity, ACL, crash recovery |
| Доверие к uninstall targets | До elevated запуска в M2 | User-writable paths, signatures/identity, executable replacement, supported commands |
| Backup и confidence | До очистки в M3 | Объекты, метаданные, restore, retention, evidence, false-positive policy |
| Матрица дополнительных Windows | После измерений M1 | Windows 10/ARM64/Server: поддержка, CI и ограничения |
| Подпись, updater и хостинг releases | До M6 | Владение ключами, сертификат, поставщик, offline и ошибки |
| GitHub remote и доступ | По отдельному указанию владельца | Название, visibility, права, PR/CI rules |

Открытый вопрос не блокирует подготовку документации. Он блокирует конкретную
реализацию или выпуск там, где без ответа нельзя выполнить критерий безопасности.
