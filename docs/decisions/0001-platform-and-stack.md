# ADR-0001: Windows-first и Rust с Tauri/React

Дата: 25 ноября 2026 года.
Статус: начальное решение для прототипа; проверка в конце M0. Это рабочая исходная
точка по запросу проекта на Rust с современным UI; окончательная оценка UI ещё впереди.

## Контекст

Нужен Windows-деинсталлятор класса BCU. Сложность сосредоточена в совместимости
Windows, правах, процессах и безопасной очистке. Интерфейс должен удобно работать
с большим списком и объяснять действия. Пользователь хочет Rust и современный UI.

## Решение

- Первая целевая платформа — Windows 11 x64.
- Rust отвечает за domain, inventory, adapters, execution, cleanup и state.
- Tauri 2 соединяет Rust с React/TypeScript. UI использует WebView2.
- Минимальный helper на Rust выполняет административные операции через проверяемый IPC.
- UI работает с обычными правами; универсальных shell полномочий у него нет.
- Приложение локальное, без обязательного аккаунта и телеметрии.

## Альтернативы

| Вариант | Причина рассмотреть | Ограничение |
| --- | --- | --- |
| Rust + Slint | Без веб-стека; декларативный UI | Нужна отдельная проверка таблицы, доступности, лицензирования и компонентов |
| Rust + egui/iced | Rust UI и единый язык | Нужна проверка desktop UX, доступности и требуемых компонентов |
| Rust core + WinUI/C# | Сильная Windows-интеграция | Второй backend/runtime и сложность interop/поставки |

Альтернативы не признаны непригодными: сейчас выбирается быстрый проверяемый путь
к интерфейсу и системному Rust-ядру. Продукт на Tauri не является полностью Rust-only:
его frontend написан на TypeScript.

## Последствия

- Нужно поддерживать две toolchains и версионированные Rust/TS контракты.
- WebView2 — зависимость поставки, её наличие нельзя предполагать на каждой машине.
- Стандартные компоненты и web-практики не отменяют реальную проверку Narrator в desktop.
- Отдельный helper уменьшает привилегии UI, но добавляет IPC и необходимость защиты от confused deputy.
- Не обещаем размер, скорость и потребление памяти до измерений.

## Проверка

M0 должен показать большой синтетический список, поиск, выбор, keyboard/focus,
ошибку backend и RU/EN. Desktop smoke выполняется на Windows 11 x64. Если таблица,
доступность или поставка не достигают требуемого качества, до M2 сравнить с
альтернативой и оформить новый ADR. Доменное ядро при этом сохраняет независимость от Tauri.

Затрагивает UX-01–UX-03, INV-01, UN-08, DIST-01 и PRIV-01.
