# Rust Uninstaller

Диспетчер удаления программ для Windows с ядром на Rust и современным интерфейсом.
Рабочее название; окончательное имя продукта ещё не выбрано.

Цель — последовательно реализовать возможности класса Bulk Crap Uninstaller:
обнаружение программ, пакетное удаление, поддерживаемые тихие режимы и объяснимую
очистку остатков. Исходный проект служит техническим ориентиром.

## Текущее состояние

На 25 ноября 2026 года создана документационная основа проекта. Код приложения,
сборка, тесты и установщик ещё не реализованы. Все описанные возможности являются
требованиями к будущим версиям, если явно не указано обратное.

Начальные решения: Windows 11 x64; Rust для системной логики; Tauri 2 и
React/TypeScript для интерфейса; отдельный процесс для привилегированных операций.
Выбор интерфейсного стека проверяется работающим прототипом до реализации удаления.
Условия пересмотра записаны в [ADR-0001](docs/decisions/0001-platform-and-stack.md).

## Основные принципы

- Сканирование по умолчанию только читает данные и не требует администратора.
- Удаление запускается после просмотра конкретного плана пользователем.
- Системные операции выполняет Rust; интерфейс не формирует команды оболочки.
- Для остатков показываются основания связи с программой и уровень уверенности.
- Пользовательские данные сохраняются по умолчанию.
- Резервирование остатков не обещает откат стороннего деинсталлятора.
- Приложение работает локально; отправка списка программ и телеметрия не входят в базовый продукт.

## Репозиторий и лицензирование

Репозиторий изначально локальный, основная ветка — `main`. Законченные изменения
фиксируются отдельными коммитами после проверок. Remote, публикация, push и релизы
выполняются после отдельного указания владельца.

Лицензия нашего проекта пока не выбрана; разрешение на распространение по какой-либо
open-source лицензии этим README не предоставляется. Код и ресурсы BCU пока не
копируются. В исходном репозитории заявлена Apache-2.0; перед заимствованием нужно
проверить условия конкретных файлов и зависимостей, сохранить необходимые уведомления
и записать происхождение. См. [источники](docs/references.md).
