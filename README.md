# Rust Uninstaller

Диспетчер удаления программ для Windows с ядром на Rust и современным интерфейсом.
Рабочее название; окончательное имя продукта ещё не выбрано.

Цель — последовательно реализовать возможности класса Bulk Crap Uninstaller:
обнаружение программ, пакетное удаление, поддерживаемые тихие режимы и объяснимую
очистку остатков. Исходники BCU подключены как зафиксированная база для переноса
существующих модулей и правил, с сохранением авторства.

## Текущее состояние

На 25 ноября 2026 года создана документационная основа и подключён upstream BCU
как submodule `third_party/bcu`. Собственный код приложения, сборка, тесты и
установщик ещё не реализованы. Все описанные возможности являются
требованиями к будущим версиям, если явно не указано обратное.

Начальные решения: Windows 11 x64; Rust для системной логики; Tauri 2 и
React/TypeScript для интерфейса; отдельный процесс для привилегированных операций.
Выбор интерфейсного стека проверяется работающим прототипом до реализации удаления.
Условия пересмотра записаны в [ADR-0001](docs/decisions/0001-platform-and-stack.md).

## Основные принципы

- Сканирование по умолчанию только читает данные и не требует администратора.
- Удаление запускается после просмотра конкретного плана пользователем.
- Системные операции выполняет Rust; интерфейс не формирует команды оболочки.
- Для остатков показываются основания связи с программой и уровень уверенности.
- Пользовательские данные сохраняются по умолчанию.
- Резервирование остатков не обещает откат стороннего деинсталлятора.
- Приложение работает локально; отправка списка программ и телеметрия не входят в базовый продукт.

## Репозиторий и лицензирование

Основная ветка — `main`. Владелец разрешил агенту самостоятельно делать коммиты,
push и выпускать проверенные релизы. Политика — [releasing.md](docs/releasing.md).
Публичный репозиторий: [tokatim/rust-uninstaller](https://github.com/tokatim/rust-uninstaller).

Собственный код и документация публикуются под [Apache License 2.0](LICENSE).
Проект бесплатный и open source; коммерческое использование разрешено лицензией.
Сторонние файлы сохраняют свои лицензии, в том числе GPL-3.0-or-later в ObjectListView
и MIT в NBug. Их наличие в исходном BCU не означает включение в нашу сборку.
См. [уведомления](THIRD_PARTY_NOTICES.md) и [план переноса](docs/upstream-reuse.md).

Получение upstream после клонирования:

```text
git submodule update --init --recursive
```

Submodule закреплён на commit, а не автоматически обновляется до последней версии.
BCU подключён как исходный материал; его C#-код ещё не является работающим Rust-ядром.
