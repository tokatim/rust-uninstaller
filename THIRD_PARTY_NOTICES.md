## Для каждого переноса

1. Проверить лицензию source file и необходимых фрагментов/зависимостей.
2. Указать upstream project, commit, путь, исходных авторов и характер адаптации.
3. Сохранить необходимые copyright/license/NOTICE и заметное указание изменений.
4. Добавить запись о фактически включённом материале в этот документ.
5. Приложить нужные полные тексты лицензий к артефакту, который материал распространяет.

Клонирование submodule оставляет чужие исходники под их собственными условиями.
Обычный `git archive` родительского проекта не включает содержимое submodule.
Для source release с включённым upstream нужна отдельная сборка исходного архива
с полным набором применимых лицензий. Логотип и бренд BCU не становятся нашим брендом.
